## 구현 원칙

- 객체마다 클래스를 만들고 파일을 나눠 `main.py`에서 import 합니다.
- 모든 객체는 `game_world`의 레이어 리스트에 담고, `main.py` 루프에서 매 프레임 update와 draw를 호출합니다.
- 선수의 행동은 `transitions` 상태 머신으로 구현하고, 상태는 하나씩 추가합니다.
- 플레이어와 상대는 같은 Character 클래스를 쓰고, 상태 머신 이벤트를 키보드 또는 AI가 넣어 줍니다.
- 이미지는 클래스 변수로 한 번만 불러와 같은 클래스의 객체끼리 공유합니다.

| goal_left.png, goal_right.png          | 골대 (그림은 이미지 바깥쪽 76px 영역만) | 2         |
| 폰트 (.ttf, 추가 예정)                 | 점수, 타이머, 라운드, 화면 글자         | 2         |
| ui_gauge_frame.png, ui_gauge_fill.png  | 스킬 게이지 틀과 채움                   | 3         |
| 신규 2종 스프라이트 시트 (추가 예정)   | 신규 유형 4, 5                          | 4         |

선수 시트 줄 구성 (위에서부터, 3종 모두 같음)

| 줄 | 동작           | 프레임 | 용도                          |
| -- | -------------- | ------ | ----------------------------- |
| 0  | idle (대기)    | 4      | 가만히 서 있을 때             |
| 1  | run (달리기)   | 6      | 좌우 이동                     |
| 2  | jump (점프)    | 5      | 점프 중 (올라감, 내려옴)      |
| 3  | kick (킥)      | 5      | Space 킥 동작                 |
| 4  | tackle (태클)  | 4      | 하드태클 (수비형 필살 스킬)   |
| 5  | fall (넘어짐)  | 4      | 태클에 맞아 넘어짐            |
| 6  | trick (개인기) | 5      | 트릭스터 (개인기형 필살 스킬) |
| 7  | power (파워샷) | 5      | 파워샷 (파워형 필살 스킬)     |

pico2d는 이미지 아래쪽이 y = 0이므로, 코드에서는 `(7 - 줄) * 256`을 clip 위치로 씁니다.
