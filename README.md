# 헤드 토너먼트

32강 토너먼트를 5경기 연달아 이겨 우승하는 2D 사이드뷰 1대1 헤드 사커 게임입니다.
캐릭터 유형마다 능력치와 필살 스킬이 다르고, 상대는 매 경기 랜덤으로 등장합니다.

- 과목: 2D 게임 프로그래밍
- 제작자: 김도영 (2023180006)
- 개발 환경: Python, pico2d, transitions, py_trees (상대 AI 행동 트리)
- 화면: 1280 x 720 (16:9), 풀스크린 실행

## 실행 방법

```
pip install pico2d transitions py_trees
python main.py
```

## 게임 규칙

- 한 경기는 60초이며 골을 더 많이 넣은 쪽이 이깁니다. 동점이면 먼저 넣는 쪽이 이기는 골든골입니다.
- 32강, 16강, 8강, 4강, 결승까지 최대 5경기를 치릅니다.
- 이기면 다음 라운드, 지면 탈락하고 처음부터 다시 도전합니다.
- 상대는 매 경기 랜덤으로 정해지고, 라운드가 올라갈수록 상대 능력치와 반응 속도가 높아집니다.
- 공을 건드리면 스킬 게이지가 차고, 가득 차면 필살 스킬을 쓸 수 있습니다.
- 토너먼트가 끝나면 닉네임(영어, 숫자 최대 10글자)을 입력해 랭킹에 기록합니다. 상위 10개 기록만 남습니다.

## 화면 흐름

메인 화면 → 로딩 → 캐릭터 선택 → 로딩 → 경기 (32강 ~ 결승) → 결과 / 우승 → 닉네임 입력 → 메인 화면

메인 화면에서 랭킹을 볼 수 있고, 경기 중 ESC로 일시정지 메뉴(계속하기 / 다시 시작 / 메인 메뉴)를 엽니다.

## 조작

| 입력  | 동작                        |
| ----- | --------------------------- |
| ← →   | 이동                        |
| ↑     | 점프                        |
| Space | 킥 (결과 화면에서는 다음)   |

## 캐릭터 유형 (수치는 1~5 단계)

| 유형       | 속도 | 파워 | 필살 스킬                                      |
| ---------- | ---- | ---- | ---------------------------------------------- |
| 수비형     | 5    | 3    | 하드태클: 공을 빼앗고 상대를 넘어뜨림          |
| 개인기형   | 4    | 2    | 트릭스터: 공을 발에 붙이고 상대를 뚫고 돌파    |
| 파워형     | 2    | 5    | 파워슛: 공을 아주 강하게 참                    |
| 골키퍼형   | 3    | 3    | 철벽 방어: 잠시 동안 몸에 닿는 공을 모두 막음  |
| 공중형     | 3    | 4    | 오버헤드킥: 높이 뛰어올라 공중에서 내리꽂음    |
| 거인형     | 2    | 4    | 거대화: 잠시 동안 몸이 커져 공중볼을 따냄      |
| 감아차기형 | 3    | 4    | 드라이브슛: 높이 떴다가 골대 앞에서 뚝 떨어짐  |
| 무회전형   | 4    | 3    | 무회전슛: 회전 없이 흔들리며 날아감            |

점프 높이는 모든 유형이 같습니다.

## 상대 AI

상대 AI는 py_trees 행동 트리로 동작합니다. 매 프레임 공을 보고(Sense Ball) 블랙보드에 기록한 뒤,
위에서부터 조건이 맞는 가지 하나를 실행합니다.

1. 유형별 필살기 가지 (슛 거리, 태클 거리 등 맞는 순간에만 사용)
2. Kick: 공이 발 앞에 있으면 참
3. Block Shot: 날아오는 슛을 점프해 머리로 막음
4. Header: 떨어지는 공에 맞춰 점프
5. Jump Over: 뒤로 넘어간 낮은 공을 뛰어넘음
6. Defend: 골대가 위험하면 공과 골대 사이로 돌아감
7. Position: 공 뒤쪽 위치로 이동

## 개발 단계

1. 최소 플레이: 선수, 공, 골대, 이동, 점프, 킥, 충돌
2. 경기 규칙: 점수, 60초 타이머, 골든골, 경기 리셋
3. 캐릭터와 상대: 유형별 능력치와 스킬, 캐릭터 선택, 랜덤 상대 AI
4. 토너먼트 완성: 5경기 진행, 난이도 상승, 화면 UI, 연출, 랭킹, 밸런스 조정

## 폴더 구성

- `main.py`: 게임 실행 파일
- `game_framework.py`, `game_world.py`: 모드 전환과 게임 월드 관리
- `*_mode.py`: 화면별 모드 (메인, 로딩, 선택, 경기, 일시정지, 닉네임, 랭킹)
- `character.py`, `ball.py`, `opponent_ai.py`: 선수, 공, 상대 AI
- `character_data.py`, `tournament.py`, `records.py`: 유형 데이터, 토너먼트 진행, 랭킹 기록
- `resource/`: 이미지 등 리소스
- `docs/`: 기획서와 개발 문서
