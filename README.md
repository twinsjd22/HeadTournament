# 헤드 토너먼트

32강 토너먼트를 5경기 연달아 이겨 우승하는 2D 사이드뷰 1대1 헤드 사커 게임입니다.
캐릭터 유형마다 능력치와 필살 스킬이 다르고, 상대는 매 경기 랜덤으로 등장합니다.

- 과목: 2D 게임 프로그래밍
- 제작자: 김도영 (2023180006)
- 개발 환경: Python, pico2d, transitions
- 화면: 1280 x 720 (16:9), 풀스크린 실행

## 게임 규칙

- 한 경기는 60초이며 골을 더 많이 넣은 쪽이 이깁니다. 동점이면 먼저 넣는 쪽이 이기는 골든골입니다.
- 32강, 16강, 8강, 4강, 결승까지 최대 5경기를 치릅니다.
- 이기면 다음 라운드, 지면 탈락하고 처음부터 다시 도전합니다.
- 상대는 매 경기 랜덤으로 정해지고, 라운드가 올라갈수록 상대 능력치가 높아집니다.
- 공을 건드리면 스킬 게이지가 차고, 가득 차면 필살 스킬을 쓸 수 있습니다.

## 조작

| 입력     | 동작      |
| -------- | --------- |
| ← →    | 이동      |
| ↑       | 점프      |
| Space    | 킥        |
| Z (예정) | 필살 스킬 |

## 캐릭터 유형 (수치는 1~5 단계 초안)

| 유형     | 속도 | 파워 | 점프 | 필살 스킬                                  |
| -------- | ---- | ---- | ---- | ------------------------------------------ |
| 수비형   | 5    | 3    | 3    | 하드태클: 공을 빼앗고 상대도 넘어뜨림      |
| 개인기형 | 4    | 2    | 3    | 트릭스터: 상대와 부딪혀도 공을 뺏기지 않음 |
| 파워형   | 2    | 5    | 2    | 파워샷: 공을 매우 강하게 차 넣음           |

## 개발 단계

1. 최소 플레이: 선수, 공, 골대, 이동, 점프, 킥, 충돌
2. 경기 규칙: 점수, 60초 타이머, 골든골, 경기 리셋
3. 캐릭터와 상대: 유형별 능력치와 스킬, 캐릭터 선택, 랜덤 상대 AI
4. 토너먼트 완성: 5경기 진행, 난이도 상승, 화면 UI, 밸런스 조정
